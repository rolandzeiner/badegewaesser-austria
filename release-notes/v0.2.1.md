## Summary
The card editor now saves only the options you change, and a cleared title falls back to the bathing water's name again.

## Breaking changes
_None._

## Fixed
- Changing any option in the card editor wrote all five `show_*` toggles into the card's YAML, so later changes to the defaults never reached that card. The editor now saves only what you changed (#5).
- Clearing the card's title left an empty heading. The card now shows the bathing water's name, as it does when no title is set (#5).
- A `badegewaesser_austria:` entry in `configuration.yaml` is now reported as unsupported instead of being silently ignored. The integration is set up through the UI only, as before.

<details><summary>Internal changes</summary>

- The card is built, type-checked, linted and formatted with Vite+ (`vp`), replacing the separate Rolldown, TypeScript and Vitest packages. The bundle behaves the same.
- New tests cover the card's version check and its Reload button.
- Strict mypy passes on Home Assistant 2026.10 (#10).

</details>

## Compatibility
- Home Assistant: ≥ 2025.6.0
- HACS: ≥ 2.0.0
